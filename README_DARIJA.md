# Assembly proxy iOS 1.132.10 - نسخة التجربة

## علاش هاد النسخة مختلفة؟

الملف اللي كيجي من اللعبة الفعلية `assembly-csharp-patch` حجمو **147,904 bytes** وداخل UnityFS عندو **71 تعديل IFix**. البروكسي القديم كان كيعوّضو بملف فيه غير 3 تعديلات، وبالتالي كيمسح الهوتفيكس ديال اللعبة من الملف المعوّض.

هاد النسخة مبنية على **الملف الأصلي اللي وفرتيه**، وكتحافظ على 71 تعديل أصلي وكاتزيد 3 تعديلات ديال ملف الباز (74 مجموع). حنا ما بدلناش لوجيك الباز، ولكن عاودنا ترقيم مراجع metadata ديالو باش يتوافق مع IFix المدموج. كتستعمل نفس بنية UnityFS وتصحح Sizes وSHA-1 وGZIP وFileinfo أوتوماتيكياً.

**ما كاينش ضمان ديال التشغيل داخل اللعبة.** الفحوصات المحلية كتثبت سلامة بنية الملفات وتوافق الهاشات، ماشي أن محرك اللعبة غادي يقبل الملف، ولا أن iOS غادي يقرأ localConfig.

## خطوات Windows (داخل فولدر ASSEMBLY_PROXY_IOS13210)

وقف البروكسي القديم بـ Ctrl+C، حل CMD داخل هاد الفولدر، ثم نفذ:

```cmd
py -m pip install -r requirements.txt
py verify.py
py -m unittest discover -s tests -v
py run.py --host 0.0.0.0 --port 7777
```

كتقدر تستعمل `RUN_WINDOWS.bat` من بعد تثبيت المتطلبات.

## فقط ملفات الأسامبلي

الملفات اللي كتتقدم للهاتف:

- `payload/assembly-csharp-patch.gz`: الملف المضغوط اللي كيقدمو البروكسي عبر HTTP 200/206.
- `payload/assembly-csharp-patch.bytes`: UnityFS بعد فك GZIP.
- `payload/fileinfo-line.txt`: السطر بالهاشات الجديدة.
- `config/localConfig.json`: نسخة من الملف اللي صيفطتي. البروكسي **ما كينقلوش** للهاتف.

البروكسي كيتعرف على طلبات `.../gameassetbundles/codepatch/assembly-csharp-patch.<hash>` وكيبدل فقط سطر `codepatch/assembly-csharp-patch` داخل `.../ABHotUpdates/.../fileinfo`. ماكيبدلش باقي الملفات وما فيه لا مفاتيح ولا حجب تقارير ولا تعطيل كشف.

## تحسين إضافي للشبكة

`run.py` كيستعمل `--allow-hosts` باش ميعترضش خدمات Apple، وتسجيل الدخول، وطلبات أخرى ما محتاجينش نعدلوها. كيعترض TLS غير من `core-*` و`dl-*` ديال CDN اللعبة، وكيخلي باقي طلبات HTTPS تمر كما هي.

هادشي مفيد حيت آخر log فيه مشكل HTTP/2 `Bearer ` فطلب تسجيل دخول آخر؛ ممكن اعتراض TLS العام كان كيسببو. إذا ظهر رابط CDN جديد خارج هاد النطاق، خاص تضيفو لفلتر `ASSET_CDN_RE` بعد ما تتأكد منه.

## بخصوص localConfig.json على iOS

نسخة الملف هي:

```json
{"testCodePatch":true}
```

ما كاين حتى دليل داخل IFix الخام أن هاد المفتاح كيتقرا من `Documents`. لوجيك الباز فيه نصوص ديال **مسارات Android الثابتة** وكيستعمل `System.IO.File.Delete` لهاد المسارات؛ ممكن loader ديال اللعبة هو اللي كيتعامل مع `testCodePatch` بشكل مستقل. لذلك وضع JSON داخل `Documents` ماكيضمنش تشغيل الباتش.

## إعادة البناء

إلى احتجتي تعاود تبني من source اللي جا فالباكيج:

```cmd
py build_assembly.py
py verify.py
```

التحقق مقصور على الإصدار iOS 1.132.10 اللي بعتي؛ تغيير ملف الـsource لإصدار آخر خاص مراجعة جديدة.

## التشخيص بعد التشغيل

إذا بان `fileinfo codepatch row replaced` و `SERVED ASSEMBLY locally ... (HTTP 206)` راه البروكسي عطى البايتات للهاتف. إلا اللوجيك ما بانش، خاص فحص لوجات تحميل IFix داخل اللعبة (`loaded`, `rejected`, `deserialize`, `method not found`... إلخ) ماشي تغيير proxy عشوائياً. وقارن كذلك تشغيل اللعبة دون بروكسي، قبل ما تعتمد هاد التعديل.
